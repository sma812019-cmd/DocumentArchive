وثيقة سياسة الخصوصية وحماية البيانات

تاريخ السريان: نوفمبر 2026

مرحباً بك في تطبيق أرشيف المستندات — الإدارة المتقدمة (Document Archive Pro v6.0)، المطوّر بواسطة المهندس سمير الكمالي. نلتزم بأعلى معايير الخصوصية والأمان لحماية بياناتك وأرشيفك المؤسسي.

1. معالجة وتخزين البيانات

يعمل البرنامج بالكامل كتطبيق مكتبي محلي مستقل (Standalone Desktop Application):

  • تخزين محلي 100%: تُحفظ جميع المستندات، ملفات PDF، الصور، وقواعد البيانات محلياً على جهاز المستخدم أو على الخادم الشبكي الداخلي (UNC / Local Network) الذي يحدده المستخدم.
  • انعدام التتبع السحابي: لا يقوم البرنامج برفع، نقل، أو تتبع نصوص المستندات، أرقام السندات، أو البيانات المالية لأي خوادم خارجية أو سحابية.

2. محرك قراءة النصوص (OCR)

تتم جميع عمليات التعرف الضوئي على الحروف (OCR) باللغتين العربية والإنجليزية ومعالجة وتحسين الصور محلياً بالكامل عبر معالج الجهاز (Offline On-Device Processing) دون إرسال الصور لأي طرف خارجي.

3. الصلاحيات والأذونات المطلوبة

  • وحدات التخزين (File System): لقراءة المستندات، حفظ الملفات، إنشاء النسخ الاحتياطية المضغوطة، وتشفير المجلدات.
  • الماسح الضوئي وكاميرا الويب: تُستخدم أجهزة الإدخال فقط عند طلب مسح أو تصوير مستند جديد بتدخل يدوي من المستخدم.
  • الشبكة المحلية (Local Network): لدعم مزامنة المستندات على المجلدات المشتركة، أقفال القراءة/الكتابة، وحماية التعديلات المتزامنة.

4. الأمان وتشفير الملفات

يتوافق البرنامج مع تقنيات التشفير المعتمدة في نظام التشغيل (مثل Windows EFS) للمجلدات المحلية لضمان منع الوصول غير المصرح به للملفات المخزنة.

Welcome to Document Archive Pro (v6.0), developed by Eng. Samir Al-Kamali. We are committed to maintaining the highest security and privacy standards for your document repository.

1. Data Storage & Privacy

Document Archive Pro operates entirely as an offline, standalone desktop application:

  • 100% Local Storage: All scanned documents, metadata, PDFs, and databases are stored strictly on your local computer or chosen local network share (UNC/Tailscale).
  • Zero External Telemetry: No scanned document contents, financial voucher data, or private user credentials are ever transmitted to external cloud servers.

2. On-Device OCR Processing

All Optical Character Recognition (Arabic & English OCR) and image optimization algorithms run locally using the host computer's resources without communicating with third-party web services.

3. Permissions Used

  • Storage & File System: Required to organize files, create automated backups, and support directory encryption.
  • Webcam / Scanner Hardware: Activated only upon manual user initiation to capture physical documents.
  • Local Network Connectivity: Used exclusively to manage shared UNC folders, concurrent access locks, and team collaboration.

4. Security & Encryption

The application supports native Windows Encrypting File System (EFS) integration for directory-level security against unauthorized local access.
