# أرشيف المستندات - الإدارة المتقدمة (Document Archive Pro)

نظام مكتبي احترافي متكامل مصمم خصيصاً لإدارة، أرشفة، وحماية المستندات والوثائق الرسمية والمالية بكفاءة عالية وأمان تام لنظام ويندوز.

---

## 🚀 أبرز مميزات البرنامج:
* **محرك OCR متقدم:** دعم التعرف الضوئي على الحروف (OCR) للغتين العربية والإنجليزية لاستخراج النصوص من المستندات والصور بدقة عالية.
* **الاستخراج الآلي للحقول:** توفير الوقت عبر استخراج البيانات والحقول المهمة تلقائياً من المستندات المؤرشفة.
* **حماية وتشفير متطور:** اعتماد تشفير ملفات Windows EFS وقفل شبكي UNC لضمان سرية وأمان البيانات الحساسة.
* **إدارة الصلاحيات والمستخدمين:** نظام تحكم صارم يحدد صلاحيات الإضافة، التعديل، والحذف لكل مستخدم.
* **واجهة مستخدم عصرية:** تصميم عصري يدعم الوضع الليلي (Dark Mode) مع واجهات سلسة ومريحة للعين.
