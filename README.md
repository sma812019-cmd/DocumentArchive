# أرشيف المستندات — Document Archive

واجهة ويب عربية تجريبية لإدارة أرشيف مستندات محلي في المتصفح. هذه الواجهة ليست تطبيق Windows متصلاً بخادم، ولا توفر مزامنة بين الأجهزة.

## التشغيل

افتح [`archive/index.html`](archive/index.html) أو انشر المستودع على استضافة صفحات ثابتة. قد تعمل بعض ميزات التخزين بشكل أفضل عند فتح الصفحة عبر خادم محلي أو استضافة HTTPS.

في أول تشغيل، بيانات الدخول الافتراضية هي `admin` / `123`. تسجيل الدخول وإدارة الحسابات محليان في المتصفح فقط، وكلمات المرور ليست محمية كما ينبغي لنظام حقيقي؛ لا تستخدمها لحماية معلومات حساسة.

## الميزات

- إضافة المستندات والملفات، والبحث والتصفية والتنزيل والحذف.
- حفظ البيانات والملفات في IndexedDB داخل المتصفح الحالي.
- استخراج نص OCR من الصور عبر مكتبة Tesseract التي تُحمّل من شبكة CDN، وتصدير Excel عبر مكتبة تُحمّل عند الطلب.
- إنشاء نسخة احتياطية واستعادتها. قد تحتوي النسخة الاحتياطية على محتوى الملفات، لذا تعامل معها كملفات حساسة واحفظها في مكان آمن.

## حدود وخصوصية البيانات

البيانات محلية لهذا المتصفح والجهاز، ولا يوجد خادم أو مزامنة مع تطبيق مكتبي. مسح بيانات الموقع أو تعطل المتصفح قد يؤدي إلى فقدان الأرشيف؛ أنشئ نسخاً احتياطية دورية وتحقق منها. لا تحفظ مستندات سرية أو حساسة في هذه الواجهة التجريبية.

تحتاج ميزتا OCR وتصدير Excel إلى اتصال بالإنترنت لتحميل المكتبات الخارجية. لا يتضمن المستودع حالياً إعداداً للاختبارات أو البناء. صفحة [`privacy.html`](privacy.html) مستقلة عن واجهة الأرشيف؛ وجودها لا يثبت تنفيذ ميزات تطبيق Windows أو خدمات خادمية.

## التحقق اليدوي

افتح صفحة الأرشيف في متصفح حديث، ثم جرّب إضافة ملف والبحث والتصفية والتنزيل والحذف، وأعد تحميل الصفحة للتأكد من بقاء البيانات في المتصفح نفسه. جرّب أيضاً إنشاء نسخة احتياطية واستعادتها.
