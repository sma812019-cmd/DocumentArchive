# DocumentArchive

أرشيف مستندات مع واجهة عربية تجريبية، إلى جانب صفحة سياسة الخصوصية.

## صفحة الأرشيف

افتح [`archive/index.html`](archive/index.html) أو شغّل مجلد المستودع عبر استضافة صفحات ثابتة. تتضمن الصفحة البحث والتصفية وإضافة الملفات وحذفها. تُخزَّن البيانات والملفات في IndexedDB داخل المتصفح الحالي؛ لا يوجد في هذه الواجهة خادم أو مزامنة أو اتصال بقاعدة بيانات التطبيق المكتبي. لا ترفع إليها مستندات سرية، واحتفظ بنسخ احتياطية لأن مسح بيانات المتصفح قد يحذف الأرشيف.

هذه الواجهة منفصلة عن تطبيق Windows وميزات OCR والتشفير وإدارة المستخدمين المذكورة في سياسة الخصوصية؛ وجود الصفحة وحده لا يثبت تنفيذ تلك الميزات في هذا المستودع.

## التحقق

لا يتضمن المستودع حالياً إعداداً للاختبارات أو البناء. للتحقق يدوياً، افتح صفحة الأرشيف في متصفح حديث، جرّب الإضافة والبحث والتصفية والتنزيل والحذف، ثم أعد تحميل الصفحة للتأكد من بقاء البيانات في المتصفح نفسه.
